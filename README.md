# 砺智 · Brain Training

一款原创、移动端优先的浏览器益智游戏合集。当前包含认知训练、经典数字游戏和三国华容道，并支持本地成绩记录、触屏操作与积分辅助。

## 游戏列表

- 数字闪忆
- 颜色冲突
- 极速运算
- 路径回溯
- 随机唯一解数独
- 2048
- 3×3 / 4×4 / 5×5 华容滑块
- 三国华容道
- 扫雷

## 本地运行

项目不依赖构建工具，直接打开 `index.html` 即可。若浏览器限制本地资源，可启动任意静态服务器：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 技术说明

- 单文件 HTML、CSS、JavaScript 应用
- `localStorage` 保存个人最佳、积分和训练进度
- 数独生成器会验证唯一解
- 华容道使用状态压缩 BFS 提供实时辅助
- 所有主要游戏支持触屏操作
