# 砺智 · Brain Training

一款原创、移动端优先的浏览器益智游戏合集。当前包含认知训练、经典数字游戏和三国华容道，并支持本地成绩记录、触屏操作与积分辅助。

- 2048

- 三国华容道

- 3×3 至 7×7 最短解分级开关灯
- 5×5 至 9×9 随机唯一解数和（Kakuro）

- 5×5 至 9×9 随机可解美术馆

## 本地运行

项目不依赖构建工具，直接打开 `index.html` 即可。若浏览器限制本地资源，可启动任意静态服务器：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 技术说明

- 无构建工具的模块化 HTML、CSS、JavaScript 应用
- `localStorage` 保存个人最佳、积分和训练进度
- 数独生成器会验证唯一解
- 数织生成器支持棋盘尺寸与开局提示量双轴难度，并验证唯一解、避免近期关卡重复
- 逻辑矩阵生成器通过候选排列求解器验证线索只有唯一答案
- 开关灯生成器从合法点击倒推，并用逐行追灯求解器计算最短解
- 数和生成器从合法答案计算横纵提示，并用回溯求解器验证唯一解、避免近期关卡重复
- 数桥从连通桥网反向生成；星星战役通过求解器加入必要排除格以保证唯一解
- 推箱子使用 BFS 验证生成关卡可解，AI 会从玩家当前局面重新规划路径
- 美术馆生成器先搜索完整照明方案，再计算数字墙提示
- 华容道使用状态压缩 BFS 提供实时辅助
- 所有主要游戏支持触屏操作

## 项目结构

```text
index.html              页面结构与脚本加载清单
css/styles.css          全局及各游戏界面样式
js/core.js              存档、报告、公共 UI 与共享工具
js/bootstrap.js         导航、游戏入口和全局事件
js/games/*.js           每款游戏一个独立文件
js/tests.js             浏览器回归测试
assets/                 图片素材
docs/plans/             开发与重构计划
```

新增游戏时，在 `js/games/` 创建独立脚本，通过 `registerGame(id, launcher)` 注册入口，在 `GAMES` 清单登记卡片，并把脚本加入 `index.html`。不要把游戏逻辑重新写回页面文件。
