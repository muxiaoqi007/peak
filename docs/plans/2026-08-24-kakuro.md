# 数和（Kakuro）Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 新增一款可在手机端完整游玩的数和游戏，题目可解、唯一解、按难度分级且近期不重复。

**Architecture:** 游戏放在独立经典脚本 `js/games/kakuro.js`，通过共享 `registerGame` 接入。生成器从合法答案与题盘结构计算横纵和提示，再由回溯求解器校验唯一解；必要时加入少量锁定起始数字。界面复用全屏游戏壳，提供数字键盘、候选笔记、撤销、查错和积分提示。

**Tech Stack:** 原生 HTML、CSS、JavaScript，localStorage 存档，浏览器内回归测试。
