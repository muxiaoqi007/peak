# 数织游戏 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在砺智中加入支持 6×6 至 10×10、可调开局提示量、可触屏操作且关卡不重复的数织游戏。

**Architecture:** 在现有 `index.html` 单文件架构中加入数织 UI、生成器和求解器。生成器先创建具有图案结构的答案，再计算行列线索，并用约束传播与回溯验证唯一解；开局提示格从答案中抽取，数量作为第二难度轴，最近关卡签名记录在本地进度中避免重复。

**Tech Stack:** HTML、CSS、原生 JavaScript、localStorage、现有浏览器测试工具。

---

### Task 1: 注册游戏与进度迁移

**Files:**
- Modify: `index.html`
- Test: `window.MindPeakTests`

**Steps:**

1. 在 `GAMES` 增加 `nonogram` 游戏卡片，并加入启动映射。
2. 将本地进度版本升级，新增 `seen.nonogram`，保留旧用户数据。
3. 增加迁移测试，确认旧版本记录不会丢失。

### Task 2: 生成线索、求解与唯一性验证

**Files:**
- Modify: `index.html`
- Test: `window.MindPeakTests`

**Steps:**

1. 实现由布尔行列计算连续段线索的纯函数。
2. 枚举与线索匹配的全部行模式，并使用列约束回溯求解。
3. 生成 6～10 尺寸的结构化随机图案，排除空行、空列和过度稀疏图案。
4. 只接受解数为 1 的关卡，并用签名排除最近 80 局。
5. 添加线索正确性、唯一解和尺寸覆盖测试。

### Task 3: 双轴难度菜单

**Files:**
- Modify: `index.html`

**Steps:**

3. 增加玩法教程，解释数字、连续色块、空格标记和胜利条件。

### Task 4: 棋盘交互与辅助

**Files:**

**Steps:**
